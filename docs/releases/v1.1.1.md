# Vector Engine v1.1.1

## Release summary

v1.1.1 is a packaging and documentation patch on top of v1.1.0. No public API surface, behavior, or evidence artifacts changed; see `docs/releases/v1.1.0.md` for the full evidence package (stability, matrix, and reproducibility contracts, which remain valid for this patch).

## Changes

- Added PyPI `classifiers` and `[project.urls]` (Homepage, Repository, Issues, Documentation) to `pyproject.toml`.
- Closed out the v1.1.0 release checklist and populated the performance table in `docs/releases/v1.1.0.md` from regenerated evidence artifacts.
- Colab demo notebooks now install standalone via `pip` and link directly from GitHub instead of static Drive copies.
- Fixed a build failure under newer setuptools caused by a redundant `License ::` classifier conflicting with the SPDX `license = "MIT"` field (PEP 639).

## Stable public surface

Unchanged from v1.1.0. See `docs/api_stability.md` and `tests/test_api_stability.py`.
